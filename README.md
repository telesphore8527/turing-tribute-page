# Alan Turing Tribute Page

A clean, semantic, and responsive tribute page dedicated to **Pr. Alan Turing**, celebrating his revolutionary contributions to computer science, cryptanalysis, and artificial intelligence. 

This project was built from scratch as part of the **freeCodeCamp Responsive Web Design** curriculum.

## 🚀 Live Demo

You can view the live deployment here:[https://github.com/telesphore8527/turing-tribute-page]  

## 🛠️ Features

- **Responsive Visuals:** Employs modern CSS layouts to ensure the text, timeline, and images scale gracefully across mobile, tablet, and desktop viewports.
- **Interactive Links:** Includes secure external links (`target="_blank"`) pointing to extensive biological records.
- **Clean Chronology:** Features a well-structured chronological timeline capturing the core milestones of Turing's life, from his academic achievements at Cambridge to his vital code-breaking work at Bletchley Park.
- **Elegant Typography:** Utilizes carefully adjusted font weights, custom blockquotes, and specific text alignments for an editorial feel.

## 🧰 Tech Stack

- **HTML5:** Semantic architecture (`<main>`, `<figure>`, `<figcaption>`, `<ul>`).
- **CSS3:** Custom styling, layout constraints (`max-width`), custom blockquote borders, and responsive styling.

## ⏱️ Timeline Highlights Covered
**191:** Birth in London.

**1936:** Publication of "On Computable Numbers", introducing the theoretical **Turing Machine**.  
**1940:** Design of the Bombe at Bletchley Park, breaking the German Enigma cipher.  
**1950:** Introduction of the Turing Test for Artificial Intelligence.  
**2013:** Official posthumous Royal Pardon granted by Queen Elizabeth II.
